# 🩺 MedScan — AI Symptom Checker

An AI-powered symptom checker that analyzes your symptoms and gives possible conditions, urgency levels, and health guidance — all in seconds.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?style=for-the-badge&logo=flask&logoColor=white)
![Groq](https://img.shields.io/badge/Groq-LLaMA%203.3-F55036?style=for-the-badge)

---

## ✨ Features

- Add symptoms via tags or quick-add buttons
- Enter age, sex, and pre-existing conditions for personalized results
- AI ranks 3–5 possible conditions by likelihood
- Emergency alert for life-threatening symptom combinations
- Recommended next steps and lifestyle advice

---

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python, Flask |
| AI | LLaMA 3.3 70B via Groq API |

---

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`
